# 🎮 Demo Mode - Тестирование с MOCK данными

## Обзор

Демо-режим позволяет тестировать плеер без подключения к реальному backend. Используются MOCK данные для каталога, треков и пользовательского состояния.

## Запуск демо

### Вариант 1: Простой запуск (рекомендуется)

```bash
# 1. Установить зависимости
npm install

# 2. Запустить в режиме разработки
npm run dev

# 3. Открыть http://localhost:5173/demo.html
```

### Вариант 2: Использовать DemoApp компонент

```tsx
import { DemoApp } from '@vbonline/player'

// DemoApp уже настроен с MOCK данными
<DemoApp />
```

## Конфигурация демо

Файл: `src/lib/demoConfig.ts`

```typescript
export const DEMO_MODE = true // Включить/выключить демо

// Получить MOCK каталог
const catalog = getDemoCatalog()

// Получить MOCK состояние пользователя
const userState = getDemoUserState()

// Загрузить с имитацией задержки
const catalog = await loadDemoCatalog()
```

## Особенности демо-режима

✅ **Работает без backend**  
✅ **Все функции доступны**  
✅ **Переключение тем работает**  
✅ **Плейлисты создаются**  
✅ **Лайки сохраняются**  
❌ **Офлайн режим отключен**  
❌ **PWA отключен**  
❌ **Реальные файлы не загружаются**  

## Отключение демо-режима

Для production использования:

```typescript
// src/lib/demoConfig.ts
export const DEMO_MODE = false
```

Или используйте обычный `PlayerApp` с реальной конфигурацией:

```tsx
import { PlayerApp, setPlayerConfig } from '@vbonline/player'

setPlayerConfig({
  // Ваша реальная конфигурация
  catalog: {
    publicDiskKey: 'https://disk.yandex.ru/d/YOUR_KEY',
  },
  // ...
})

<PlayerApp renderHeader={...} />
```

## Тестирование функций

### 1. Воспроизведение аудио
- Нажмите на любой аудио трек
- Используйте кнопки play/pause
- Перемотка работает через timeline

### 2. Просмотр видео
- Нажмите на видео трек
- Видео откроется в плеере
- Работают все контролы

### 3. Чтение текстов
- Нажмите на текстовый трек
- Откроется viewer с MOCK контентом

### 4. Плейлисты
- Создайте новый плейлист
- Добавьте треки
- Переключайтесь между плейлистами

### 5. Темы
- Откройте sidebar
- Выберите тему из переключателя
- 4 темы доступны: Rastaman, Rastaman Light, Jaipur, Moon Dub

### 6. Лайки
- Нажмите на сердечко у трека
- Трек появится в разделе "Лайки"

## Файлы демо-режима

- `src/lib/mockData.ts` - MOCK данные
- `src/lib/demoConfig.ts` - Конфигурация демо
- `src/DemoApp.tsx` - Демо приложение
